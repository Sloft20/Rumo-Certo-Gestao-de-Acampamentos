# 🏕️ Rumo Certo - Gestão Financeira de Acampamentos

Um sistema de gestão financeira *Mobile-First* desenvolvido para otimizar o controle de caixa, inscrições e despesas de acampamentos e eventos. Focado na usabilidade de campo, o sistema conta com suporte a funcionamento offline e uma interface fluida baseada em "Caixa Expresso" para despachar filas rapidamente.


## ✨ Funcionalidades Principais

*   **Caixa Expresso (Gaveta Dinâmica):** Fluxo de abates de dívidas e novos lançamentos numa *Bottom Sheet* integrada, sem recarregamento de páginas.
*   **Offline-First:** Sistema de fila inteligente que guarda os lançamentos localmente quando não há internet e sincroniza com o banco de dados assim que a rede volta.
*   **Anexos na Nuvem:** Upload de comprovativos (PDF ou imagens) via PIX diretamente no ato do lançamento.
*   **Relatórios em PDF:** Geração instantânea de balancetes financeiros completos com resumo de receitas, despesas e estatísticas de público.
*   **Modo Privacidade & Dark Mode:** Ocultação rápida de saldos para uso do tablet em público e alternância de temas nativa.
*   **Gestão de Metas:** Painel analítico para acompanhar o progresso de arrecadação versus o limite de gastos em tempo real.
